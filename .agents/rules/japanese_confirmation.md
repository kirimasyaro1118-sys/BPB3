# ユーザーへの許可・確認に関する日本語ガイドライン

## 1. 実行前の日本語解説の徹底
ターミナルコマンドの実行（`run_command`）、ファイルの作成・変更・削除、外部アクセスなどの許可や操作を行う場合は、**必ずツール実行の直前にチャット画面で日本語による説明を提示**してください。

## 2. 説明に含めるべき内容
- **操作内容**: 具体的にどのようなコマンドやファイル変更を行おうとしているか
- **必要な理由**: なぜその操作が必要なのか
- **影響とリスク**: 実行によってファイルが上書きされる、新規ファイルが作成される、外部通信が発生するなど
- **Submitを押した後の動作**: 「Submit」または「Approve」ボタンを押すと何が起きるか

## 3. 質問・選択肢の日本語化
ユーザーに質問（`ask_question`）や選択肢を提示する場合は、質問文だけでなく**選択肢のボタン名もすべて日本語**で作成してください。
